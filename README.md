# taoyuan-water-service

# 桃園市政府水務局便民資訊服務

> 整合桃園市政府水務局主網頁各項資訊，設計成容易查詢的頁面，讓一般民眾輕鬆了解補助申請、業務資訊、常見問答與線上服務。

## 功能特色

- **便民服務入口**：整合水務局各項線上服務連結，按類別分類
- **業務資訊一覽**：12 個科室業務說明與服務項目
- **常見問答 (FAQ)**：8 項民眾常見問題與解答
- **相關法規**：水利法、下水道法等重要法規連結
- **聯絡資訊**：電話、地址、服務時間、電子郵件等
- **搜尋功能**：支援關鍵字搜尋所有內容
- **分類篩選**：按「補助申請」「資訊查詢」「線上申請」「業務資訊」「常見問答」篩選
- **自動更新**：每天上午 10:00 自動更新資料並部署網站

## 使用方式

### 1. Fork 本專案

點擊 GitHub 頁面右上角的「Fork」按鈕，將本專案複製到您的帳號下。

### 2. 啟用 GitHub Pages

1. 進入專案的 **Settings > Pages**
2. **Source** 選擇 **GitHub Actions**
3. 系統會自動部署網站

### 3. 手動執行（可選）

進入 **Actions** 頁籤，選擇「桃園市政府水務局便民資訊服務」工作流程，點擊 **Run workflow** 手動觸發更新。

## 頁面內容

### 便民服務入口
- 下水道雲端智慧管理系統（補助申請）
- 水情資訊網（資訊查詢）
- 地下水管理智慧平台（資訊查詢）
- 桃園網路e指通（線上申請）
- 水利設施參訪預約系統（線上申請）
- 申報案件查詢（資訊查詢）
- 市管河川及區域排水公開資訊（資訊查詢）
- 重大點源放流水監測查詢（資訊查詢）
- 龜山水肥站預約系統（線上申請）
- 檔案應用專區（線上申請）
- 容積移轉專區（資訊查詢）

### 常見問答
- 污水下水道用戶接管申請
- 水情資訊查詢
- 山坡地容積移轉申請
- 污水下水道工程補助
- 水利設施參訪預約
- 排水溝堵塞通報
