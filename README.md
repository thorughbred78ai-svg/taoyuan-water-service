# taoyuan-water-service
# 桃園市政府水務局便民資訊服務

> 整合桃園市政府水務局主網頁各項資訊，設計成容易查詢的頁面，讓一般民眾輕鬆了解補助申請、業務資訊、常見問答、交通資訊、政府資訊公開與線上服務。

## 功能特色

- **便民服務入口**：18 項水務局線上服務連結，按「補助申請」「資訊查詢」「線上申請」分類
- **交通資訊**：水務局地址、公車站牌、乘車規劃指引
- **政府資訊公開**：會計專區、統計專區、補助專區等 10 項公開資訊
- **業務資訊一覽**：12 個科室業務說明與服務項目
- **常見問答 (FAQ)**：10 項民眾常見問題與解答
- **相關法規**：水利法、河川管理辦法、下水道等重要法規連結
- **聯絡資訊**：電話、地址、服務時間、電子郵件、官方網站
- **搜尋功能**：支援關鍵字搜尋所有內容
- **分類篩選**：按類別快速篩選便民服務、業務資訊、常見問答、政府資訊公開
- **自動更新**：每天上午 10:00 自動更新資料並部署網站

## 使用方式

### 1. Fork 本專案

點擊 GitHub 頁面右上角的「Fork」按鈕，將本專案複製到您的帳號下。

### 2. 啟用 GitHub Pages

1. 進入專案的 **Settings > Pages**
2. **Source** 選擇 **GitHub Actions**
3. 系統會自動部署網站

### 3. 手動執行（可選）

進入 **Actions** 頁籤，選擇「桃園市政府水務局便民資訊服務」工作流程，點擊 **Run workflow** 手動觸發更新。
