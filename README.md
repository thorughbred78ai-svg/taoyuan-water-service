# taoyuan-water-service

# 桃園市政府水務局便民資訊服務

> 透過政府公開 API，整合桃園市政府水務局相關資訊，讓一般民眾容易查詢了解補助申請、資訊查詢等內容，並可線上申請或詢問。

## 功能特色

- **即時水情資訊**：水位站、雨量站即時監測資料
- **福利補助查詢**：整合桃園市各項福利補助政策說明及申請資格
- **便民服務連結**：提供線上申辦、案件查詢、預約系統等入口
- **聯絡資訊**：水務局電話、地址、服務時間等資訊
- **自動更新**：每天上午 10:00 自動抓取最新資料並部署網站

## 使用方式

### 1. Fork 本專案

點擊 GitHub 頁面右上角的「Fork」按鈕，將本專案複製到您的帳號下。

### 2. 啟用 GitHub Pages

1. 進入專案的 **Settings > Pages**
2. **Source** 選擇 **GitHub Actions**
3. 系統會自動部署網站

### 3. 手動執（可選）

進入 **Actions** 頁籤，選擇「桃園市政府水務局便民資訊服務」工作流程，點擊 **Run workflow** 手動觸發更新。

## 技術說明

本專案使用以下技術：

- **GitHub Actions**：自動化資料抓取與部署（每天上午 10:00 執行）
- **Python**：資料整合與處理
- **GitHub Pages**：靜態網站託管
- **桃園市政府資料開放平台 API**：資料來源

API 格式採用桃園資料開放平台標準格式：
```
https://data.tycg.gov.tw/api/v1/rest/datastore/{dataset_id}?format=json
```
